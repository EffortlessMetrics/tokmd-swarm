## RC3 browser acceptance receipt

The exact released browser artifact must prove all of the following in one
consumer run:

```text
released tarball downloaded from the RC3 GitHub Release
exact tagged application and released WASM served
worker version equals 1.15.0-rc.3
worker capability reports zipball: true
ZIP file input is enabled after worker readiness
ZIP load button is enabled after worker readiness
known ZIP fixture loads
supported lang/module/export/analyze operations return fresh non-empty output
receipt/download behavior is valid
unexpected console and page errors are absent
```

A local `wasm-pack` build, source test, or capability string without enabled
controls is not this receipt.

## Non-claims and inactive channels

Optional syntax, AST, mutation, and coverage signals remain advisory unless a
downstream policy promotes them. Release topology, package, artifact,
attestation, exact-container, and exact-consumer proofs remain gating
requirements for their release stage. This release makes no UB-absence claim
and no automatic merge verdict. The inactive Homebrew, AUR, Scoop, and WinGet
prototypes remain outside the supported 1.15 distribution surface.

## Stable closeout

After stable verification, record GitHub assets, checksums, attestations,
representative crates, Cargo install, Nix, Action binary/container, GHCR exact
and mutable tags, and browser/WASM results. Then restore a fresh
`## [Unreleased]`, update `NOW`, `NEXT`, and `ROADMAP`, perform one consolidated
closeout import if needed, and leave both repositories graph-aligned.
