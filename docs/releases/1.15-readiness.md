## RC3 preparation requirements

The RC3 release-preparation PR must run the following commands against clean,
committed source. Results from RC1 or RC2 do not satisfy RC3 after the browser
behavior change.

```text
cargo fmt-check
cargo gate-check
cargo xtask version-consistency
cargo xtask publish-surface --json --verify-publish
cargo xtask doc-artifacts --check
cargo xtask docs --check
cargo xtask proof-policy --check
cargo xtask check-no-panic-family --strict
cargo test --workspace --all-features
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo deny --all-features check
cargo xtask publish --dry-run
npm --prefix web/runner test
npm --prefix web/runner run build:wasm:archive-zip
```

Also require:

```bash
cargo xtask affected \
  --base origin/main \
  --head HEAD \
  --json-output target/proof/affected-release-1.15-rc.3.json

cargo xtask proof \
  --profile affected \
  --base origin/main \
  --head HEAD \
  --plan \
  --plan-json target/proof/proof-plan-release-1.15-rc.3.json \
  --evidence-json target/proof/proof-evidence-release-1.15-rc.3.json
```

The affected planner must report zero unknown files. Package and publish checks
must run after the bounded release-prep slice is committed; a dirty-tree refusal
is not the authoritative result. A local timeout remains `not_run`, not a pass
or a product failure, and needs a terminal hosted or adequately budgeted result.

The final RC3-prep head requires a fresh exact-head Codex review with
`blocking_findings=0` and terminal green required CI. The repository has one
human maintainer; a second-human GitHub approval object is not part of the
control.

## RC3 publication topology

Before tagging:

1. Freeze unrelated swarm merges for the import window.
2. Prove publication is an ancestor and swarm is ahead by the intended range.
3. Import the exact swarm tip into `EffortlessMetrics/tokmd` with a deliberate
   merge commit, never squash or rebase.
4. Assert the publication merge has exactly two parents.
5. Fast-forward swarm to the publication merge.
6. Restore any temporary settings bypass.
7. Require `publication_ahead=0` and `swarm_ahead=0`.
8. Run candidate proof against that unchanged aligned publication commit.
9. Tag only the candidate-proven commit.
